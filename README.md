# Sampritha J Gowda — 3D Portfolio

> A highly interactive, modern 3D portfolio showcasing my skills, projects, and experience as a **Machine Learning Engineer** and **Full Stack Developer**. Built with cutting-edge web technologies to deliver an immersive and dynamic user experience.

🌐 **Live Demo:** [portfolio-ch28.vercel.app](https://portfolio-ch28.vercel.app/)

---

## ✨ Features

- **Immersive 3D Graphics** — Interactive 3D models built with Three.js and React Three Fiber
- **Modern UI/UX** — Clean, responsive layouts designed with Tailwind CSS
- **Fluid Animations** — Smooth page transitions and element animations powered by Framer Motion
- **Projects Showcase** — Interactive display of advanced projects including Gesture Control (Jetson Nano), Facial Emotion Recognition, AI Study Planner, and Scribble Clone
- **Type-Safe Codebase** — Built with TypeScript for reliability and maintainability

## 🚀 Getting Started

### Prerequisites

- Node.js `v18+`
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Samprithajgowda/portfolio.git
   ```
2. **Navigate to the project directory**
   ```bash
   cd portfolio
   ```
3. **Install dependencies**
   ```bash
   npm install
   ```
4. **Start the development server**
   ```bash
   npm run dev
   ```
5. Open [http://localhost:3000](http://localhost:3000) in your browser.
